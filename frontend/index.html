SYSTEM INSTALLATION & SETUP GUIDE

1. Edge Telemetry Gateway

1 Initialize Python Environment
Create a dedicated virtual environment in the backend directory and activate it:
cd backend/ python -m venv venv # Windows: .\venv\Scripts\activate # Linux/macOS: source venv/bin/activate
2 Install Core Gateway Dependencies
Install dependencies required for telemetry streaming and static serving:
pip install -r requirements.txt
3 Launch Kiosk Edge Server
Run the FastAPI uvicorn server locally. By default, this hosts the web dashboard on port 8000:
uvicorn app.main:app --reload --port 8000
⚡ One-Click Simulation Runner
Alternatively, auto-configure virtualenv and launch the browser using the root script:
# Windows: .\scripts\run_simulation.ps1 # Linux/macOS: ./scripts/run_simulation.sh

2. Central Production Stack

1 Orchestrate Infrastructure via Docker
Launch the database (PostgreSQL), memory store (Redis), object storage (MinIO), and tracing pipelines:
docker-compose -f deployment/docker/docker-compose.yaml up -d
2 Run Central Dashboard APIs
Start the high-throughput clinician dashboard service from the backend package:
cd backend/ uvicorn dashboard.api.main:app --reload --port 8000
3 Start the AI Inference Engine Requires AI deps
Start the real-time AI critical alert engine (onnxruntime, sklearn) on port 8001:
cd backend/ uvicorn ai.main:app --port 8001

3. SevraOS live ISO Compilation

1 Setup Build Workspace (Arch Linux)
Install the standard `archiso` compilation utilities on a host Arch Linux system:
sudo pacman -S archiso
2 Compile the Branded ISO
Compile the operating system using root permissions. The target ISO generates in the `out/` folder:
cd sevraos/ sudo mkarchiso -v -w ./work -o ./out ./
3 Simulate Bedside Gateway
To test the complete telemetry ingestion flow, run the simulator script:
python simulations/simulate.py
4 Run Virtually in QEMU VM (Optional)
To test and run the compiled live ISO virtually before deploying to hardware, run:
# Windows: .\scripts\run_vm_qemu.ps1 # Linux/macOS: ./scripts/run_vm_qemu.sh
